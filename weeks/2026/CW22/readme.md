**Repository Structure**

This weekly folder represents the aggregation layer for the reporting
period.

Weekly artifacts are generated from underlying incident records and
organized into publication, reporting, and governance materials.

The folder structure separates:

- incident data

- weekly reporting artifacts

- governance documentation

- visualization assets

- publication materials

**Traceability**

Weekly reporting artifacts are derived from incident records included
within the weekly dataset.

The manifest serves as the primary reference point for package scope,
included records, generation metadata, and artifact traceability.
