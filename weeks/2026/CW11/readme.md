**Folder Contents Overview**

This weekly folder contains the following artifacts:

- **manifest.md** --- the weekly metadata anchor defining scope and
  incident identifiers.

- **incidents.csv** --- the canonical incident dataset for the week.

- **taxonomy report** --- the dataset analytics output describing
  incident taxonomy distributions.

- **prevention normalization report** --- the normalized prevention
  action coverage derived from incident records.

- **governance notes** --- qualitative governance observations recorded
  during weekly closure.

These artifacts together represent the finalized weekly bundle for CW11
2026.
