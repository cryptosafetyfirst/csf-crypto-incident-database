# CSF Orchestrator Specification

This directory contains the public specification for the
CSF Crypto Incident Intelligence Pipeline.

The orchestrator defines:
- how incidents are identified and ingested,
- how deterministic analytics are produced,
- how weekly outputs are governed and audited,
- and how immutability and reproducibility are enforced.

## Authoritative Document

The authoritative specification is:

- **CSF-Orchestrator-Spec-v1.0.md**

All weekly datasets published in this repository declare
the orchestrator version used to generate them.

## Change Control

All changes to the orchestrator are recorded in `CHANGELOG.md`
and governed by the semantic versioning rules defined in Section 11
of the specification.
